# 종이 발기인 동의서 등록

1. 종이 동의서를 찍어 구글 드라이브 `AIP 종이 발기인 (비공개)/1_받은함` 에 올린다. (폴더는 운영자 개인 드라이브, 공유 없음)
2. Claude에게 "종이 발기인 처리해 줘"라고 하면 사진을 읽어 같은 폴더에 `검토표 YYYY-MM-DD` 시트를 만든다.
   - 열: 이름, 생년월일, 성별, 직업, 주소, 휴대폰, 자택전화, 작성일, 서명, 사진ID, 확인필요 (성별·전화는 비어도 됨, 여러 쪽 스캔은 사진ID에 `#p3` 처럼 쪽 번호)
   - 글씨가 불분명한 칸은 `확인필요` 에 이유를 적는다. 서명이 없으면 `서명` 을 비운다.
3. 운영자가 시트를 사진과 대조해 고치고 `확인필요` 를 비운다.
4. aiparty.kr/admin → "종이 동의서 등록" 에 시트를 복사해 붙여넣고 `검사` → `등록`.
   - DB 함수 `admin_import_paper_founders` 가 형식·만 18세·서명·중복(이름+생년월일, 휴대폰)을 검사한다.
   - 등록된 행은 `source = 'paper'`, `paper_ref` = 드라이브 사진 파일 ID.
5. Claude가 등록된 사진을 `2_등록완료` 로 옮긴다. 종이 원본은 결성신고 제출용으로 보관한다.

DB 적용: `db/2026-11-28_paper_founders.sql` 을 Supabase SQL Editor에서 한 번 실행한다.
